# 📊 E-commerce Sales Data Analytics Project

## 📌 Project Overview
This project presents an end-to-end data analytics solution on e-commerce sales data to uncover meaningful business insights, identify trends, and support data-driven decision-making.

The project uses PostgreSQL as the database, Python (with psycopg2) for database connectivity, and data analysis libraries for cleaning, analysis, and visualization.

---

## 🎯 Objective
Developed an end-to-end data analytics solution to analyze large-scale e-commerce sales data, identify key business trends, and generate actionable insights to support business decisions.

---

## 🛠️ Tech Stack
- Python (Pandas, NumPy, Matplotlib, Seaborn)
- SQL (PostgreSQL)
- psycopg2 (Python PostgreSQL connector)
- Database: PostgreSQL
- IDE: Visual Studio Code

---

## 🔄 Workflow
1. Database connection using psycopg2 (PostgreSQL)
2. Data extraction using SQL queries
3. Data cleaning & preprocessing using Python
4. Exploratory Data Analysis (EDA)
5. KPI calculation
6. Data visualization using Python
7. Business insights generation

---

## 📊 Key KPIs
- Total Sales Revenue  
- Total Profit  
- Total Orders  
- Average Order Value (AOV)  
- Top Customers  
- Loss-making Products  

---

## 🗄️ Database & SQL Usage (PostgreSQL + psycopg2)

- Connected to PostgreSQL database using `psycopg2`
- Executed SQL queries directly from Python
- Extracted structured datasets for analysis
- Performed joins, aggregations, and filtering using SQL

Example use cases:
- Monthly sales trend analysis  
- Category-wise performance  
- Customer-level behavior analysis

- Discount vs Profit Impact  
- Sales Contribution by Segment

---

## 📌 Key Insights
- Sales vary significantly across different regions  
- A small group of customers contributes a large share of revenue  
- High discounting negatively impacts profit margins  
- Certain product categories consistently underperform  
- Specific cities dominate overall sales performance
